# Явка — учёт посещаемости

Приложение для отметки отсутствующих студентов (1 пара = 2 академических часа).

## Как получить APK

1. Создайте репозиторий на github.com (кнопка **New**), назовите его, например, `yavka`.
2. Загрузите в него все файлы из этой папки, **включая скрытую папку `.github`**.
3. Откройте вкладку **Actions**. Сборка запустится сама после загрузки (5–10 минут).
   Если не запустилась: Actions → «Сборка APK» → **Run workflow**.
4. Когда появится зелёная галочка, откройте сборку и внизу в разделе **Artifacts** скачайте `yavka-apk`.
5. Распакуйте архив, перенесите `app-debug.apk` на телефон и установите
   (разрешите установку из неизвестных источников).

## Как изменить приложение

Вся логика и интерфейс находятся в файле `www/index.html`. После правки загрузите его в репозиторий, и APK соберётся заново.

Данные хранятся на телефоне и не удаляются при обновлении приложения, если не менять `appId` в `capacitor.config.json`.

## Кнопка «Поделиться»

Создаёт Excel-таблицу в формате ведомости (лист на каждый месяц по числам, плюс лист «Подробно» с предметами) и открывает меню отправки Android.

## Программа для компьютера (Windows)

Папка `desktop` и файл `.github/workflows/build-windows.yml` собирают одиночный `.exe` без установки.
Actions → «Сборка Windows» → скачать `yavka-windows` из Artifacts → распаковать → запустить `Yavka-1.0.0.exe`.
Кнопка «Поделиться» на компьютере сохраняет таблицу Excel в выбранную папку.
